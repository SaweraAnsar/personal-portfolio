BIOTECH / AI02

AMR Guardian AI

An AI-powered antibiotic resistance prediction and clinical decision support project.

View GitHub ↗Live Demo ↗

Project overview

An intelligent platform designed to predict antibiotic susceptibility and support clinical decision-making.

Problem addressed

Supporting antibiotic susceptibility prediction and clinical decision-making through an AI-powered workflow.

Solution

Patient Data → Laboratory Results → AI Analysis → S/I/R Prediction → Antibiotic Recommendation → Clinical Report

Key features

Patient and infection data input; AI susceptibility prediction; S/I/R classification; confidence scores; antibiotic recommendation; downloadable clinical reports; interactive dashboard.

My role

Sawera Ansar, Biochemistry: Team Leader, Project Manager and UI/UX developer, Research Analyst, GitHub Repository Manager, Quality Assurance and Testing, Database Coordinator, Presentation and Submission Lead.

Responsibilities

Coordinated the project, built the frontend, led documentation, and led project submission.

Technology stack

Frontend: React + TypeScript · Backend: Supabase · Database: PostgreSQL · AI Engine: OpenAI LLM · Authentication: Supabase Auth · Deployment: Native.builder · Charts and Analytics: Recharts
